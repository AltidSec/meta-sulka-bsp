How to Report a Potential Vulnerability?
========================================

If you would like to report a public issue (for example, one with a released
CVE number), or a not-yet released issue, please either open an issue on
Codeberg / GitHub, or get in touch with the layer maintainer:
esa DOT jaaskela AT suomi24 DOT fi

Branches maintained with security fixes
---------------------------------------

This project maintains security fixes for the latest Yocto LTS version, and
for the previous LTS if that is still "fairly recent". See the [documentation](https://altidsec.com/sulka/documentation/about.html#supported-yocto-versions)
for the current status.
